# pilot-001：合成介绍页

状态：未实现。本文件只定义后续功能 PR 的需求。bootstrap 不添加 `index.html`、`styles.css`、`main.js` 或页面测试。

## 目标

在本仓库增加一个纯本地的合成介绍页，用来演示已批准的 AI 工作流试跑。页面内容是虚构的项目说明，不是旧 TypeB2B 的迁移，也不是对外发布的站点。

## 页面内容

- 标题表达 “AI Workflow Pilot”
- 一段用途说明
- 三步流程
- 一段试跑边界说明
- 页内锚点导航。按钮最多跳到页内锚点

## 实现约束

- 使用 HTML 与 CSS。只有确有需要时才加少量本地 JavaScript
- 不引入前端框架、构建器和第三方运行时依赖
- 不包含表单、登录、统计、后台或模型 API
- 不使用真实客户资料、第三方图片、第三方字体、外链服务或生产密钥
- 不导入旧项目素材
- 不部署到 GitHub Pages、VPS、域名或任何其他环境

## 验收

功能 PR 完成时，页面需要满足：

- HTML 语义清楚，标题层级合理
- 页内导航的每个锚点都有对应目标
- 手机与桌面宽度下不出现横向溢出
- 基本键盘访问可用，正文与背景的对比度可读

本地用浏览器打开文件即可检查。这个检查证明不了公网发布，也不代替 `npm test`。

## 测试要求

功能 PR 先加入会失败的页面断言，再实现页面让同一断言通过。断言至少覆盖：

- 页面标题与必需章节
- 页内锚点目标存在
- 没有表单、远程脚本或外部资源
- 没有意外的网络入口
- 如果加入本地 JavaScript，为它的行为补确定性测试

禁止删除这些断言、把它们改成恒真，或用 skip 跳过。文本和结构断言只是最小回归，不代表完成了浏览器渲染或无障碍审计。视觉、键盘和对比度检查单独作为人工项记录。

## 非目标

- 本 bootstrap PR 不实现上述页面，也不加入页面断言
- 不连接旧项目、服务器或生产凭据
- 不把介绍页发布到仓库以外的任何地方
